## Simple DNS (SDNS)
Данный проект написан для домашнего DNS сервера для более удобной маршрутизации домашних сервисов.

Это крайне простой сервер тут нет особенных технологий, но опять же для домашней сети это идеальный вариант.


---

Работает на Raspberry Pi 3B [(*тык*)](https://www.raspberrypi.com/products/raspberry-pi-3-model-b/)
